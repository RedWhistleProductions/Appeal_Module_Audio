Playlist paths and automatic advancement

Prefix commands with Audio. The bundled PlayAll.txt is in Resources/Audio/Playlist.

Audio Load_Play_List "PlayAll.txt"
Audio Auto_Play_Next 1
Audio Debug On
Audio Auto_Play_Next_Status
Audio Play

// Playback advances automatically while your script continues.
// Disable automatic advancement:
Audio Auto_Play_Next 0

To use another directory, call Audio Set_Playlist_Path "Resources/Audio/My Playlists" before loading a playlist. A trailing slash is optional. Relative paths are resolved from the process working directory.

Playlist entries use a quoted title followed by a music-relative filename, for example:

"RPG 1" Samples/RPG_1.mp3

Auto_Play_Next replaces the former Set_Auto_Play setter. Auto_Play_Next_Status replaces the former Auto_Playing query (briefly named Auto_Play_Next). The configuration status field is now Auto_Play_Next_Status bool 0.
